# Basic React Projects

A collection of React projects built while learning React and modern frontend development.

## Projects

### 01. Password Generator

A password generator built with React that allows users to create customizable passwords.

**Features:**
- Adjustable password length
- Numbers toggle
- Special characters toggle
- Copy password to clipboard
- Password strength indicator

**Tech Stack:** React, JavaScript, Vite, Tailwind CSS, SVG

**Live Demo:** [View Project](https://basic-react-projects-delta.vercel.app/)
